## Architecture Candidates

1. **Import module depth**: `importController`, `processImport`, and `importBatch` expose storage keys and batch mechanics across several modules. Deepen the import module so the interface is "owned upload -> bounded batches -> history rows"; this improves locality for ownership, size limits, status transitions, and tests.
2. **Auth module seam**: browser session handling is split between Better Auth cookies, direct session-table bearer lookup, URL token handoff, and localStorage. Collapse the interface to cookie-backed browser sessions, and introduce a separate adapter only if non-browser clients need tokens later.
3. **Verification module/interface**: CI currently treats formatting/linting as the verification interface. Make `verify` a deep repo-level module hiding the right static, test, and build gates behind one command.
