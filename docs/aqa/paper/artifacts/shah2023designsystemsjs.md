# Shah and Kamuni (2023) -- DesignSystemsJS - Building a Design Systems API for aiding standardization and AI integration

**Venue:** CoNTESA 2023

## What It Says

- Proposes a JavaScript library and API intended to standardize design-system requirements across teams.
- Frames inconsistency as a problem of divergent interpretation and implementation across software teams.
- Focuses on design-system standardization, not on testing consistency, monorepo tooling, or TypeScript package environments.
- Is adjacent to the paper topic only in the narrow sense that it treats standardization as a way to reduce variation.
