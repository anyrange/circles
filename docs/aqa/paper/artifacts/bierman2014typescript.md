# Bierman, Abadi, and Torgersen (2014) -- Understanding TypeScript

**File:** `sources/FTS-submitted.pdf`
**Venue:** Lecture Notes in Computer Science, 2014
**BibTeX key:** `bierman2014typescript`

## What It Says

- TypeScript was designed to support easier development of large-scale JavaScript applications.
- The language preserves common JavaScript idioms and allows gradual adoption instead of requiring a full rewrite.
- The type system intentionally includes pragmatic unsoundness to remain usable with existing JavaScript libraries and codebases.
- Formalization helps separate sound and unsound parts of the language design.

## Key Quotes

> "enable easier development of large-scale JavaScript applications" (p. 1)

> "not statically sound by design" (p. 1)

## How to Use in Paper

- **Related Work:** Explain why large TypeScript codebases prioritize compatibility and incremental maintenance.
- **Discussion:** Support the argument that toolchains for TypeScript monorepos must work with mixed and evolving codebases.
